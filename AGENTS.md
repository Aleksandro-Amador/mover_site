# Agent Instructions

## Code Style
- Use 2 spaces for indentation (not tabs).
- Follow existing patterns in the codebase for naming and structure.

## Build Commands
- `npm run dev` to start the development server.
- `npm run build` to build for production.
- `npm run lint` to lint the code.

## Architecture
- This is a React application built with Vite and TypeScript.
- Styling uses Tailwind CSS.
- Components are located in the `src/` directory.
- Main entry point is `src/main.tsx`, with routing in `src/App.tsx`.

## Project Structure
- `src/assets/` contains images, icons, and logos.
- Key components: `App.tsx`, `DoeAgora.tsx`, `CozinhaSolidaria.tsx`, etc.

For more details, see [README.md](README.md).
